## 🎯 Quick Start

### Option A: Auto-Run with Script (Easiest)
```bash
# Linux/Mac
chmod +x start.sh
./start.sh

# Windows
start.bat
```

### Option B: Manual Setup
```bash
pip install -r waste_app/requirements.txt
streamlit run waste_app/app.py
```

### Option C: Docker
```bash
docker-compose up
# Visit: http://localhost:8501
```
